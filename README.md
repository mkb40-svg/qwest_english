# English Quest: Lost in London

Образовательная игра-квест для изучения английского. Статический проект: без сборки, без сервера, все пути относительные, поэтому работает на GitHub Pages по адресу вида `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`.

## Публикация на GitHub Pages
1. Создайте на github.com новый публичный репозиторий (например, `english-quest`).
2. Нажмите «uploading an existing file» и загрузите **содержимое** папки `english-quest` (файл `index.html` должен лежать в корне репозитория, а не во вложенной папке). Включите в загрузку папки `css`, `js`, `content` и файл `.nojekyll`. Нажмите Commit changes.
3. Откройте Settings → Pages. В разделе Build and deployment выберите Source: Deploy from a branch, ветка `main`, папка `/ (root)`, затем Save.
4. Через 1-2 минуты сайт появится по адресу, который GitHub покажет вверху страницы Pages.

Обновление: загрузите изменённые файлы тем же способом, сайт обновится сам.

## Локальный запуск
    python3 -m http.server 8000   # затем откройте http://localhost:8000
Двойной клик по `index.html` не сработает: браузер не загружает JS-модули и JSON с диска.

## Структура
- `content/chapters.json`: главы, эпизоды, задания (типы: c диалог, a аудио, g пропуск, s говорение, w письмо)
- `js/app.js`: логика и экраны; `js/store.js`: сохранения; `js/review.js`: повторение слов по Лейтнеру; `js/speech.js`: озвучка и распознавание речи
- `sw.js`, `manifest.webmanifest`: PWA и офлайн-режим

## Как добавить эпизод
Добавьте объект в массив `e` нужной главы (глава: `n` название, `e` эпизоды, у эпизода `t` название и `steps` задания) в `chapters.json`, код менять не нужно.
